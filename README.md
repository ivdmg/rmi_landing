# Лендинг ООО «РМИ»

Статический сайт на React, TypeScript и Vite.

- `npm ci` — установка зависимостей.
- `npm run dev` — разработка и локальный просмотр.
- `npm run build` — проверка TypeScript и сборка в `dist`.
- `npm run preview` — локальный просмотр сборки.

Для размещения на статическом хостинге загрузите содержимое каталога `dist`.

Перед открытием общего доступа добавьте в блок «Реквизиты» рабочую электронную почту для заявлений по ст. 15.7 закона № 149-ФЗ и сверьте адрес с выпиской ЕГРЮЛ. Перед указанием конкретных категорий изделий уточните, какие работы компания выполняет и какие из них требуют лицензии. Категории обслуживаемого оборудования и наличие лицензии пока не подтверждены.

На странице нет форм, сторонних запросов и клиентского хранилища. При выборе публичного хостинга отдельно проверьте обработку IP-адресов и журналов доступа.

Иллюстрации сгенерированы для проекта. Шрифт Onest размещён локально, лицензия прилагается в `public/media/OFL-Onest.txt`.
