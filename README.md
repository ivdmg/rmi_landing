# Лендинг ООО «РМИ»

Статическая страница. Для локального просмотра запустите `python3 -m http.server 8000 --directory dist` и откройте http://localhost:8000. Каталог `dist` содержит весь сайт.

Перед открытием общего доступа добавьте в блок «Реквизиты» в `dist/index.html` утверждённый рабочий адрес электронной почты для заявлений по ст. 15.7 149-ФЗ. Адрес из карточки выглядит персональным и в проект не включён. Сверьте номер помещения с актуальной выпиской ЕГРЮЛ.

Страница хранит в браузере только выбранную тему. При выборе публичного хостинга отдельно проверьте его обработку IP-адресов и журналов доступа.

Иллюстрация сгенерирована специально для лендинга. Шрифт Onest размещён локально, лицензия прилагается в `dist/assets/OFL-Onest.txt`.
